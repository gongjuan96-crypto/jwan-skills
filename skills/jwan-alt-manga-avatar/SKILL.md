# Jwan Alt Manga Avatar

Create a vertical 9:16 diptych. Preserve the original portrait in the upper half. In the lower half, create a small centered manga avatar derived from the same subject, with generous white space and clear identity continuity. Keep the linework bold but controlled and the expression connected to the source. Add `Jwan` only as a small natural signature when requested. Avoid extra people, sticker clutter, unrelated text, watermarks, and distorted facial structure.

Source inspiration: Wibi Style `alt-manga-avatar`; this is a Jwan-specific adaptation.
