# jwan-pressure-crowd-editorial-poster

A reusable Jwan editorial-satire Skill for visualizing pressure, conflicting feedback and too many opinions around one central protagonist.

Version: 1.0.0

The crowd should feel excessive through layering, occlusion, gesture conflict and perspective—not through a neat grid of tiny repeated people.

## Use

- $jwan-pressure-crowd-editorial-poster，设计师坐在电脑前，周围很多很多人指着屏幕给意见。
- $jwan-pressure-crowd-editorial-poster，周围人数增加很多，但设计师仍然是中心。
- $jwan-pressure-crowd-editorial-poster，只改成正常彩色，构图不要变。
