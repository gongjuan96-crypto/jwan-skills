# Example briefs — jwan-pressure-crowd-editorial-poster

## Case 01 — Design feedback overload
- Central protagonist: designer at a monitor, back / three-quarter back to viewer
- Crowd: dense, layered, conflicting gestures
- Mode: realistic normal color
- Goal: show how density is built with foreground / midground / background overlap rather than a grid

## Case 02 — Too many opinions
- Central protagonist: isolated creator
- Crowd: compressed black-and-white editorial pressure field
- Mode: high-contrast monochrome
- Goal: demonstrate stronger visual metaphor, dramatic lighting, and conflicting direction

## Case 03 — Event producer pressure
- Central protagonist: event creative producer at a planning table
- Crowd: stakeholders, client requests, last-minute production input
- Mode: realistic color
- Goal: prove the system generalizes beyond graphic design while preserving the one-center / many-pressure narrative
