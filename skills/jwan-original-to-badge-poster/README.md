# jwan-original-to-badge-poster

Strict 9:16 original-photo-to-collectible-badge diptych by Jwan.

Version: 1.0.0

## Core idea

Exactly 50% source photo on top and 50% derivative badge field below. The top image is treated as locked source evidence, while the lower artwork converts the same memory into one centered collectible object.

The Skill defaults to no title frame, no ribbon, no bow, no extra caption, and no decorative copy.

## Use

- $jwan-original-to-badge-poster，做成搪瓷徽章，上半原图不要动。
- $jwan-original-to-badge-poster，下半改成针毡钥匙扣，缩小居中。
- $jwan-original-to-badge-poster，只增加标题“陈书悦·周岁纪念”，其他不改。
