# Jwan Original to Badge Poster

Create one vertical 9:16 poster from one supplied source photo. The poster is split exactly 50% / 50% horizontally: the source photograph occupies the upper half and a derivative collectible badge artwork occupies the lower half.

## Invocation

Use $jwan-original-to-badge-poster with one source photo. Optional input may specify badge material, commemorative wording, title frame, decorative theme, or one requested revision.

## Hard layout rules

1. Canvas: vertical 9:16.
2. Split: exactly 50% top / 50% bottom. Do not drift to 45/55 or 60/40.
3. TOP 50%: use the supplied source photo itself as the visual source. Preserve it as faithfully as possible.
4. BOTTOM 50%: create one centered derivative badge / pin / felt-keychain style artwork derived from the source.
5. Keep the derivative object smaller than the lower field and surrounded by visible negative space.
6. Add a small handwritten Jwan signature at bottom-right by default.

## Top-half fidelity

The upper half is not a reinterpretation zone.

Preserve:
- identity and apparent age
- face, hairstyle, clothing, accessories
- subject count and relative positions
- major landscape / architectural context
- camera direction and scene structure
- important props and visible event details

Allowed by default:
- subtle exposure / level cleanup
- light cropping only when necessary to fit the 50% frame without losing the key subject

Not allowed unless explicitly requested:
- redrawing
- replacing the background
- adding people or objects
- changing clothing
- restaging the scene
- stylizing the whole photo
- turning the upper half into a collage

## Badge behavior

- The lower artwork should read as one collectible object, not a second full illustration panel.
- Landscape / architecture / environmental context should remain the main body when the source is scene-led.
- Human figures should remain proportionally small when they were small in the source. Do not enlarge a distant person into a portrait.
- Use enamel pin, embroidered patch, needle-felt keychain, acrylic charm, metal badge, or similar material only when it fits the request.
- Preserve the source arrangement and visual hierarchy as far as the derivative medium allows.
- Center the badge in the lower half; avoid tilt unless requested.
- Do not add multiple badges, collage panels, frames, or secondary thumbnails by default.

## Text and decoration defaults

Default state: no title box, no ribbon, no bow, no commemorative text, no name, no age, no English micro-copy, and no decorative label.

Only add these when explicitly requested.

If the user asks for a title frame, reproduce the requested wording exactly. Examples of valid explicit requests include:
- 夏天宝宝·周岁纪念
- 陈书悦·周岁纪念
- 蒋玙翊·十六

When a special theme such as a superhero element is explicitly requested, integrate it only into the derivative lower artwork unless the user clearly asks to alter the upper photo.

## Revision discipline

If the user requests one change, modify only that element.

Examples:
- "不要标题框" -> remove title frame/text only.
- "徽章缩小一点" -> scale the lower badge down; preserve top photo and badge design.
- "增加一点奥特曼元素" -> add only the requested thematic cue to the lower derivative artwork.
- "改文字" -> change only the specified wording.
- "上面原图不要动" -> treat the upper half as locked.

## Hard avoid list

- No unequal split.
- No redrawn upper photo.
- No extra title/decorative elements by default.
- No multi-image collage.
- No tilted photo frames.
- No invented people, names, ages, dates, or places.
- No disproportionate enlargement of small figures inside scene-based badges.
- No drifting visual style during a one-element revision.

## Quality gate

Before returning:
- 9:16 is correct.
- Split is visibly 50/50.
- Upper image is the supplied photo, not a reconstructed scene.
- Lower object is one centered derivative collectible.
- Scene hierarchy and figure scale remain plausible.
- No unrequested title frame or text exists.
- Jwan signature is small and bottom-right.
- A single-element revision did not modify unrelated elements.
