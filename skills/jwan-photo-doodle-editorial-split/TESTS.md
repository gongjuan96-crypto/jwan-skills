# Acceptance tests

## 结构验收

- [ ] 每张上传照片都有单独文件，没有不同原图拼接。
- [ ] 默认宽:高=3:4，水平分割位于严格50%处（奇数像素高允许±1px）。
- [ ] 上半与输入照片内容真实对应，人物五官、姿势、手部、衣着、主体关系不变。
- [ ] 上半没有不必要的重绘、换脸、夸张HDR、假光、塑料皮肤或拉伸。

## 插画验收

- [ ] 下半提炼“瞬间与关系”，而不是全面复刻原背景。
- [ ] 幼态感的不规整细线和少量 Marker/Crayon 填色，仍具杂志式成熟构图。
- [ ] 主要区域为暖白负空间；没有填满画布。
- [ ] 只有当前照片的视觉线索，没有跨照片复用的随机道具。
- [ ] 没有新增多余人物、手或脚。

## 字体与署名验收

- [ ] 只有一条有意义的简短短语；若用户指定则准确输出。
- [ ] 图文之间有清晰的视觉关系，而非机械居中套模板。
- [ ] `Jwan` 在整张海报右下角安全范围内，微小清晰，不抢主体。

## 回归案例（文字brief）

1. **生日派对 / 双人合影**：保留两人头部方向、表情、亲近关系；下半概括互动与纪念感，不复刻气球背景。
2. **旅行风景 / 地标**：上半保留真实建筑轮廓与光影；下半仅提炼地标及一个旅行动作线索，空白优先。
3. **生活静物 / 餐食**：上半保留物体原貌；下半刻画食物特征与氛围线索，不照搬整个餐桌。
