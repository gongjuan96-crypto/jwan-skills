# Examples — Public-safe briefs

以下提供三个文字案例 brief，**不包含未经明确授权的照片或可识别儿童人像**。

## Case 01 — Birthday moment

两位孩子俏皮合照；保留头部倾斜、伸舌表情、亲近关系。下半用小比例双人手绘与少量文字回忆瞬间，不重画完整生日道具和气球背景。

## Case 02 — Travel memory

真实旅游地标照片；上半直接保留原片，下半只概括建筑识别性轮廓、一个方向/行动线索与简短手写短语，控制留白。

## Case 03 — Ordinary day

室内生活静物或家庭日常；从一个微小动作或物件轮廓提取叙事，删除不必要的场景，不堆积装饰元素。
