# jwan-spatial-type-architecture-poster

A reusable Jwan Skill for turning a word into inhabitable architecture inside a high-end 9:16 editorial poster.

Version: 1.0.0

The defining rule is simple: typography must become physical space. People cross, enter, sit on, hide behind, or move through the letters within one coherent perspective.

## Use

- $jwan-spatial-type-architecture-poster，主字 JWAN，巨型3D字母，4个人，不要平均站位。
- $jwan-spatial-type-architecture-poster，改成 floor typography，黑+芭比粉。
- $jwan-spatial-type-architecture-poster，只换人物 pose，空间结构不要改。
