# jwan-perspective-crowd-editorial-poster

A reusable Jwan Skill for high-end multi-person editorial advertising scenes with real foreground/midground/background depth.

Version: 1.0.0

It uses one dominant spatial mechanism — nested frames, converging perspective, stacked levels, or layered slabs — and explicitly rejects evenly spaced group-photo composition.

## Use

- $jwan-perspective-crowd-editorial-poster，7个人，nested frames，强烈前中后景。
- $jwan-perspective-crowd-editorial-poster，人数减到4个，但保留纵深和穿插。
- $jwan-perspective-crowd-editorial-poster，只换配色，构图不要变。
