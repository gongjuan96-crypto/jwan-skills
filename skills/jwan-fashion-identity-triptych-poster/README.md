# jwan-fashion-identity-triptych-poster

A reusable Jwan Skill for one-person, three-angle luxury fashion editorial portrait posters.

Version: 1.0.0

The same referenced person appears as left profile, front portrait and opposite profile in three tall vertical panels. Identity consistency is prioritized over fashion novelty.

## Use

- $jwan-fashion-identity-triptych-poster，暖白背景，三联时尚肖像。
- $jwan-fashion-identity-triptych-poster，三个分栏分别换不同帽子和眼镜。
- $jwan-fashion-identity-triptych-poster，只调整中间正脸大小，其他不动。
