# jwan-photo-art-diptych-poster

A Jwan Skill for 3:4 photo-to-art comparison posters.

Version: 1.0.0

The top half preserves the supplied photograph. The bottom half reinterprets the same composition in one of two controlled modes:

- travel-mixed-media
- east-asian-ink

## Use

- $jwan-photo-art-diptych-poster，travel-mixed-media，保留人物和建筑结构。
- $jwan-photo-art-diptych-poster，east-asian-ink，宣纸、破墨、飞白、大留白。
- $jwan-photo-art-diptych-poster，只把下半颜色减少，其他不改。
