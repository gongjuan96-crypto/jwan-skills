# Jwan Minimal Pet Doodle

Create one finished vertical 9:16 diptych from a supplied pet photo.

- Keep the original pet photo realistic in the upper half, preserving pose, fur, expression, toy interaction, lighting, and environment.
- Redraw the same pet in the lower half as a centered minimal playful doodle with generous white space.
- Use clean hand-drawn marker lines, a few warm flat colors, simplified but recognizable anatomy, and a light editorial-poster feeling.
- Preserve distinctive gestures such as a raised paw or a visible toy.
- Add a small handwritten `Jwan` signature only when requested.
- Do not add extra animals, logos, watermarks, unrelated text, dense stickers, or distorted anatomy.

Source inspiration: Wibi Style `minimal-pet-doodle`; this Skill is a Jwan-specific adaptation.
