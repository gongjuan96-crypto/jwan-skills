# Test checklist — jwan-event-space-render-system

## T1 — Wall / door fidelity
Pass: walls and access openings match the plan.
Fail: a corridor and hall merge into one open room.

## T2 — Object completeness
Pass: every marked object is present.
Fail: sign-in, control desk, photo area or seating disappears.

## T3 — No invention
Pass: no unrequested entrance, booth, screen or prop.
Fail: renderer adds scenic structures for aesthetics.

## T4 — Seating order
Pass: exact sofa/table sequence is preserved.
Fail: generic evenly spaced seating replaces it.

## T5 — Key visual
Pass: supplied visual remains recognizable and text hierarchy is preserved.
Fail: main title is redesigned.

## T6 — Camera-only revision
Input: "改成正视图".
Pass: same layout, new camera.
Fail: layout changes with camera.
