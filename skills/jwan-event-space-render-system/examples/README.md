# Example briefs

## Case 01 — Conference corridor + hall
Floor plan contains a corridor separated from the meeting hall by one complete wall with two doors. Sign-in and photo zones sit along the corridor wall. Preserve all circulation.

## Case 02 — Outdoor cultural market
Use an outdoor commercial plaza plan with stage, diagnosis, DIY, display, tea / food, seating and control zones. Preserve zoning exactly.

## Case 03 — Exhibition culture zone
Use printed-truss graphics and PVC display details. Add equipment display plinths only where shown in plan. No entrance gateway.
