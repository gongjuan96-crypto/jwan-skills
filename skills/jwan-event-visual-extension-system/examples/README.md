# Example briefs

## Case 01 — Conference material family
Input: one approved conference key visual.
Outputs: staff / guest / media / attendee badges, agenda, seat nameplate, folder, tote, notebook.

## Case 02 — Wayfinding system
Input: one approved key visual.
Outputs: road flags plus three directional-sign variants. No entrance gateway.

## Case 03 — Launch-event essentials
Input: one launch-event key visual.
Outputs: sign-in sheet, credential family, agenda, folder, tri-fold brochure and control-desk wrap.

Each case should demonstrate system consistency rather than isolated decoration.
