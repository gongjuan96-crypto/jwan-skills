# jwan-event-visual-extension-system

A reusable event-design Skill for extending one approved key visual into a complete, coherent family of event materials.

Version: 1.0.0

## Use

`$jwan-event-visual-extension-system，按照这张主视觉延展工作证、议程、桌牌、文件袋、手提袋和导视。`

The Skill preserves the original event identity while adapting information density and hierarchy to each physical touchpoint.

## Recommended case set

1. Conference / launch event material family
2. Outdoor cultural-market signage family
3. Premium forum / roadshow credential + agenda family
