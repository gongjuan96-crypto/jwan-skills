# Jwan Brand Touchpoint System

Build a coherent visual system for a small brand from one brief, one hero product, or one approved visual direction.

This Skill is for fast but disciplined brand expansion, not random style exploration.

## Typical inputs

- brand name
- category
- hero product
- flavor / SKU list
- slogan
- audience
- brand mood
- approved palette
- one reference visual
- packaging or product photos

## Typical outputs

- hero brand poster
- product / flavor poster series
- packaging touchpoints
- social-media cover
- product card
- menu / price card
- gift bag / box
- sticker / label
- brand touchpoint matrix presentation

## Brand lock

Preserve the following across all outputs:
- brand name
- slogan if approved
- logo / wordmark behavior
- core palette
- typography personality
- material language
- image-treatment style
- spacing / negative-space rhythm

Do not produce a different brand for every SKU.

## Product-series logic

Each SKU should be distinguishable without breaking the family.

Use controlled differentiators such as:
- one accent color
- one ingredient cue
- one small material / botanical detail
- one label line
- one product cutaway

Example:
- black sesame / red bean -> black sesame cue
- ham -> white sesame or savory ingredient cue
- Earl Grey -> tea stem / tea-leaf cue

Keep packaging, camera angle, hierarchy, and spacing stable across the series.

## Small-brand efficiency

Prioritize assets that can be used immediately:
1. hero poster
2. 2–4 SKU variants
3. social cover
4. package / bag / label touchpoints
5. one brand-matrix overview

Avoid generating dozens of speculative assets before the visual system is proven.

## Product-photo behavior

If the user supplies an actual product photo:
- preserve recognizable product shape
- preserve packaging text when legible and important
- improve lighting / staging only as requested
- do not silently replace it with a different product

## Copy behavior

Keep copy concise and useful.

Prefer:
- one Chinese headline
- one short supporting line
- short English micro-copy only when it strengthens the brand

Do not invent claims such as awards, origin, ingredients, health benefits, dates, or certifications.

## Revision discipline

- "留白更多" -> reduce density without redesigning brand identity.
- "红茶加红茶梗" -> add Earl Grey / tea cue only.
- "豆沙加黑芝麻" -> change SKU cue only.
- "三种口味分别一张" -> preserve one template family, change product cue and label.
- "中文标题缩小" -> typography scale only.

## Hard avoid list

- each SKU using a different art direction
- invented product claims
- random decorative props
- logo inconsistency
- oversized copy
- excessive mockups with no commercial use
- changing product identity during layout revisions
- clutter that destroys the brand's negative-space system

## Quality gate

Verify:
- all outputs belong to one brand family
- SKU differences are clear but controlled
- product remains recognizable
- copy is concise and factual
- social / packaging / poster assets feel related
- brand matrix shows a system rather than a collage of unrelated designs
- presentation samples may carry a small Jwan signature bottom-right
