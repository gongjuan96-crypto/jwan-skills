# Example briefs

## Case 01 — Handmade pastry brand
Hero poster plus three flavor variants, packaging and social cover. Keep one warm restrained visual system.

## Case 02 — Casual barbecue brand
Use one industrial / street-food identity across menu, poster, bag, table card and social materials.

## Case 03 — Lifestyle product
Use one clean editorial system across hero poster, product card, package label and social cover.

Cases should prove system consistency and commercial usability.
